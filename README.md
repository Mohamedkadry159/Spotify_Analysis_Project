No Days Off: Spotify Data Analysis Project Using Power BI 🎶📊
I’m excited to share this new project where I analyzed Spotify data using Power BI to extract insights about songs, artists, and musical patterns.
🔍 Some exciting statistics:
✅ There are 644 unique artists in the dataset, who have released 952 tracks.
✅ The song Blinding Lights is the most streamed of all time.
✅ Peru is the most danceable track 🕺.
✅ Approximately 57.67% of the songs are in a "Major" key, indicating a tendency toward a cheerful tone.
✅ Taylor Swift tops the list of artists with the most solo tracks.
